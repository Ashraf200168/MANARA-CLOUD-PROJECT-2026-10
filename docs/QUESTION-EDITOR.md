# محرر أسئلة الاختيار — Android 1.5.1 والواجهة 1.9.1

في التطبيق والموقع يبدأ السؤال الجديد بثلاث خانات مستقلة. اكتب الإجابة في كل خانة، وحدّد الصحيحة من الدائرة داخلها. يمكن إضافة خانات أو حذفها حتى إجابتين. تُميّز الإجابة الصحيحة بلون أخضر.

عند تعديل سؤال سابق تبقى جميع إجاباته وعددها وتحديد الصحيحة والشرح والمصدر محفوظة. حذف خانة قبل الصحيحة يحافظ على الإجابة المحددة؛ حذف الصحيحة نفسها يطلب تحديدًا جديدًا. يمكن أن تحتوي الإجابة الواحدة عدة أسطر، وتظل خيارًا واحدًا.

الخانات الفارغة والإجابات المكررة وغياب تحديد الصحيحة تُظهر رسائل واضحة قبل الحفظ. يحتفظ المحرر بمسودة الإجابات أثناء التبديل المؤقت إلى نوع سؤال آخر. يستمر الموقع في توفير «حفظ وكتابة السؤال التالي» مع إعادة البدء بثلاث خانات.

هذا التحسين يستخدم صيغة بيانات الأسئلة الحالية؛ لا يحتاج ترحيل قاعدة بيانات أو تحديث API إضافيًا. إعدادات مسارات الكتب والشهادات السابقة مشمولة في نفس المصدر والإصدار الجديد.

## إظهار التحديث

- التطبيق: أصبح الملف `release/Manara-App-v1.5.1-question-editor-roadmap-arm64.apk` جاهزًا، وقد فُحص توقيعه وتطابقه مع 1.4.1. ثبّته فوق التطبيق الحالي. للبناء مجددًا استخدم `BUILD-MANARA-APP.cmd` على جهاز البناء الأصلي.
- إذا نجح البناء سابقًا وفشلت خطوة التوقيع، استخدم `FINALIZE-MANARA-APK.cmd` لإكمال APK الموجود دون إعادة البناء. يتحقق من الإصدار وحداثة المصدر ويستخدم المفتاح الأصلي في `.android-home`؛ ملف المفتاح مستثنى من المستودع العام.
- الموقع: ارفع `Manara-Cloudflare-Question-Editor-v1.9.1.zip` إلى Deployment جديد داخل مشروع Cloudflare Pages الحالي. تضم هذه الحزمة أيضًا مسارات الكتب. إذا لم تُنشر قاعدة بيانات/API المسارات السابقة بعد، اتبع تعليمات `BOOK-ROADMAP.md` لتفعيلها.
- حزمة APK جاهزة محليًا؛ لم يُحدَّث التطبيق المثبّت أو موقع Cloudflare تلقائيًا.

## التحقق

تُختبر خانات الإجابة الافتراضية والإضافة والحذف وتتبّع الصحيحة وتوافق الأسئلة السابقة والتحقق من المدخلات في Node وFlutter. اختبارات مسارات الكتب السابقة مستمرة أيضًا. يبقى الاختبار على الهاتف الحقيقي بعد بناء APK خطوة النشر النهائية.

## النسخ والرفع إلى GitHub

شغّل `BACKUP-AND-UPLOAD-MANARA.cmd` من حساب Windows الذي أُعدت منه النسخ الاحتياطية. ينشئ نسخة بيانات وكتب جديدة ويتحقق من تشفيرها، ثم يرفع المصدر والتطبيق إلى `main` والنسخة المشفرة إلى `encrypted-backup` ويتحقق من البصمات المنشورة. يستخدم المفاتيح المحفوظة مسبقًا؛ لا تُرسلها في المحادثة.

يحفظ نتيجة التشغيل في `.tools/github-update/last-status.json`. لا يعتبر رفع APK وحده نجاحًا للعملية الكاملة إذا تعذر إنشاء النسخة أو رفعها.
