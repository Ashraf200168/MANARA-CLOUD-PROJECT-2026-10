# سجل مشروع Manara

## المرحلة المحلية

بدأ النظام كتطبيق يعمل على خادم محلي بقاعدة SQLite ويُنشر مؤقتًا عبر ngrok. احتوى الموقع على صفحة الطالب، الامتحانات والنتائج، الكتب، بنك الأسئلة، الفوائد، الأسئلة الشرعية، الدعم، ولوحة الشيخ.

## النقل السحابي — أكتوبر 2026

- نُسخت النسخة العاملة بدل إيقافها أثناء التطوير.
- نُقل مخطط البيانات من SQLite إلى Supabase PostgreSQL.
- نُقلت الكتب إلى Supabase Storage.
- بُنيت Edge Function باسم `manara-api`.
- نُشرت الواجهة على Cloudflare Pages.
- استوردت البيانات القديمة وتحققت أعداد الجداول والملفات.

## تحسين الموقع والـ PWA

- أضيف manifest وservice worker ووضع عدم الاتصال.
- أضيف تعديل معلومات الطالب.
- أضيفت تحسينات RTL والتنقل ودعم الهاتف.

## تطبيق Flutter

- تحول الحل من اختصار PWA إلى تطبيق Flutter فعلي offline-first.
- أضيفت الصفحة الشخصية والنتائج والكتب وقارئ PDF والفوائد والدعم وسؤال الشيخ.
- أضيفت مراجعة الإجابات وتسجيل الخروج والمزامنة المرئية.
- أضيف دخول الشيخ ولوحة إدارة موسعة.
- أضيف إنشاء الامتحان الكامل وتحرير أسئلته وربط طالب أو جميع الطلاب.

## الشهادات

- أضيف خيار اعتماد الامتحان للشهادة ونسبة النجاح.
- أضيف إنشاء سجل شهادة تلقائي عند نجاح الطالب.
- أضيف عرض وحفظ شهادة عربية باسم الطالب ودرجته.

## الحماية والاستمرارية

- أضيف نسخ احتياطي مشفر كل ثلاثة أيام تقريبًا.
- تشمل النسخة قاعدة البيانات والكتب مع بصمات SHA-256.
- أضيف تحقق آلي بفك النسخة بعد إنشائها.
- تحفظ النسخ في OneDrive، ويخطط لمزامنتها إلى مستودع GitHub خاص مستقل.

## الإصدار المرجعي الحالي

- الويب: Cloudflare Pages + Supabase.
- API marker: `cloud-baseline-1.8.7`.
- تطبيق Android: `1.4.1`.
- تاريخ الحالة: 27 أكتوبر 2026.
