# دليل النشر من الصفر

## 1. إنشاء مشروع Supabase

أنشئ مشروعًا جديدًا واحتفظ محليًا بكلمة مرور قاعدة البيانات. استخرج القيم التالية من إعدادات المشروع:

- Project URL
- Publishable/anon key للواجهة العامة
- Secret/service-role key للاستخدام الإداري المحلي فقط

لا تكتب المفتاح السري في Git أو تطبيق الهاتف.

## 2. ربط Supabase CLI

```powershell
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase db push
supabase functions deploy manara-api
```

رتب المهاجرات الموجودة في `supabase/migrations/` حسب الاسم. مهاجرة `initial_schema` تنشئ المخطط، ومهاجرة `exam_certificates` تضيف إعدادات الشهادة وسجلاتها.

## 3. أسرار Edge Function

اضبط أسرار الخادم من Supabase CLI أو لوحة Supabase. استخدم أسماء المتغيرات الموثقة في الكود و`.env.example`. يجب ضبط أصل Cloudflare المسموح به على رابط Pages الفعلي، ثم إعادة نشر الدالة.

## 4. نشر الواجهة على Cloudflare Pages

المشروع ثابت ولا يحتاج عملية بناء معقدة. اجعل مجلد النشر `frontend/`، ثم عدّل `frontend/cloud-config.js` بالقيم العامة الصحيحة فقط. بعد النشر اختبر:

- الصفحة العامة وتسجيل دخول الطالب.
- `/admin` أو صفحة لوحة الشيخ.
- CORS بين رابط Pages وEdge Function.
- إضافة الموقع إلى الشاشة الرئيسية وفتح وضع عدم الاتصال.

## 5. استيراد البيانات القديمة

أدوات `migration/` تنقل لقطة SQLite القديمة إلى Supabase. نفذ الاستيراد مرة واحدة فقط بعد أخذ نسخة المصدر والتحقق من سلامتها. لا تضف مجلد `imports/` إلى Git لأنه يحتوي بيانات حقيقية.

## 6. بناء تطبيق Android

راجع [MOBILE-APP.md](MOBILE-APP.md). بعد البناء انسخ ملف الإصدار المعتمد فقط إلى `release/` وسجل بصمة SHA-256.

## 7. فحص ما بعد النشر

- استدعاء health للـ API يرجع نجاحًا.
- تسجيل دخول طالب وشيخ يعملان.
- إنشاء امتحان تجريبي وربط طالب وتسليم محاولة.
- مراجعة الإجابة تعمل بعد انتهاء المدة المطلوبة.
- شهادة النجاح تظهر فقط للامتحان المؤهل.
- تنزيل كتاب وفتحه دون اتصال يعمل.
- النسخ الاحتياطي الدوري ينتهي برسالة `BACKUP SUCCESS`.
