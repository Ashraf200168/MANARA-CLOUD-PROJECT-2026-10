# تطبيق Manara Android

## الإصدار الحالي

- التطبيق: `1.4.1`
- Android versionCode في ملف الإصدار: `2006`
- الحزمة: `com.manara.manara_app`
- ملف التوزيع: `release/Manara-App-v1.4.1-full-sheikh-exam-arm64.apk`
- المعمارية: `arm64-v8a`

## الوظائف

التطبيق ليس اختصارًا للموقع. هو تطبيق Flutter بواجهات عربية RTL وذاكرة محلية. يحفظ بيانات الطالب المتاحة، النتائج، الفوائد، وفهرس الكتب، ويتيح قراءة الكتب المنزلة من داخل التطبيق. يتصل بالإنترنت عند المزامنة، فتح امتحان، تسليم إجابة، مراجعة تحديث جديد، أو مراسلة الشيخ.

لوحة الشيخ داخل التطبيق تشمل الطلاب والامتحانات وبناء الأسئلة والربط والنتائج وبنك الأسئلة والكتب والفوائد والاستفسارات والدعم وإعدادات الشهادة.

## بناء نسخة Release

```powershell
Set-Location mobile/manara_app
flutter clean
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

ملف Flutter الناتج المعتاد:

```text
build/app/outputs/flutter-apk/app-release.apk
```

قبل النشر، غيّر `version` في `pubspec.yaml` عند الحاجة، ولا تحذف إعداد التوقيع المستخدم للإصدارات المثبتة على أجهزة الطلاب. فقدان مفتاح التوقيع يمنع تثبيت التحديث فوق النسخة السابقة.

## اختبار الإصدار

1. ثبّت APK كتحديث فوق النسخة الحالية.
2. اختبر بقاء جلسة الطالب والبيانات المحلية.
3. افتح التطبيق دون إنترنت وتأكد من ظهور البيانات المخزنة.
4. أعد الإنترنت وجرّب امتحانًا وتسليمًا ومراجعة إجابة.
5. اختبر تنزيل كتاب وقراءته دون اتصال.
6. اختبر دخول الشيخ وإنشاء امتحان قابل للتعديل وربط الجميع.
7. اختبر شهادة امتحان مؤهل وامتحان غير مؤهل.

## التحقق من الملف

قارن SHA-256 للملف مع الملف الموجود بجانبه في `release/`. على Windows:

```powershell
Get-FileHash .\release\Manara-App-v1.4.1-full-sheikh-exam-arm64.apk -Algorithm SHA256
```
