# معمارية Manara Cloud

## المكونات

1. **Cloudflare Pages** يقدم ملفات `frontend/` الثابتة: صفحة الطالب، لوحة الشيخ، PWA، وواجهة العمل دون اتصال.
2. **Supabase Edge Function** في `supabase/functions/manara-api/` هي نقطة الدخول الوحيدة للعمليات التطبيقية الحساسة.
3. **Supabase PostgreSQL** يخزن الطلاب والامتحانات والأسئلة والتعيينات والمحاولات والإجابات والاستفسارات والشهادات.
4. **Supabase Storage** يخزن الكتب داخل حاوية `manara-books`.
5. **تطبيق Flutter** يستهلك نفس API، ويحتفظ بنسخة محلية من البيانات المسموح بها لتجربة offline-first.

## مسار الطلب

```text
Web / Android
      |
      | HTTPS
      v
Supabase Edge Function (manara-api)
      |--------------------|
      v                    v
PostgreSQL             Storage / Books
```

لا يتصل تطبيق الهاتف مباشرة بصلاحيات إدارية بقاعدة البيانات. المفتاح العام يحدد المشروع فقط، بينما التفويض والتحقق من جلسة الطالب أو الشيخ يتمان في الـ API.

## وضع عدم الاتصال

- الصفحة الشخصية والنتائج والفوائد وفهرس الكتب تحفظ محليًا بعد المزامنة.
- الكتب التي ينزلها الطالب تبقى على الجهاز وتفتح في قارئ PDF المدمج.
- الامتحان، تسليمه، مراجعة الإجابات الجديدة، ورسائل الشيخ تحتاج اتصالًا بالشبكة.
- عند عودة الاتصال يجلب التطبيق أحدث البيانات ويحدث النسخة المحلية.

## الشهادات

يحدد الشيخ على مستوى الامتحان ما إذا كان يمنح شهادة، ويحدد نسبة النجاح. بعد تسليم محاولة ناجحة ينشئ النظام سجل شهادة ثابتًا باسم الطالب ودرجته، ويمكن للتطبيق توليد وحفظ صورة شهادة عربية RTL.

## حدود الثقة

- لا يوضع المفتاح السري في الموقع أو التطبيق.
- لا تعتمد صلاحية الشيخ على إخفاء زر في الواجهة؛ التحقق يتم في الـ API.
- النسخ الاحتياطية لا تدخل المستودع العام حتى لو كانت مشفرة.
