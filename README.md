# برنامج القراءة الفردية — Manara Cloud

منصة عربية متكاملة لإدارة برنامج القراءة الفردية، وتشمل موقعًا سحابيًا وتطبيق Android يعمل بأسلوب **offline-first** ولوحة تحكم كاملة للشيخ.

> حالة الإصدار: نسخة تشغيلية بتاريخ 27 أكتوبر 2026. الواجهة مستضافة على Cloudflare Pages، والبيانات والـ API والكتب على Supabase.

## روابط التشغيل

- الموقع: <https://manara-cloud-preview.pages.dev/>
- واجهة API: <https://zgzqoxxhiwrzxsgoqyyb.supabase.co/functions/v1/manara-api>
- آخر تطبيق Android: [Manara App v1.4.1](release/Manara-App-v1.4.1-full-sheikh-exam-arm64.apk)
- النسخ اليدوي الفوري: [Manara Backup EXE](release/Manara-Backup-Now.exe)

## ما يقدمه النظام

### للطالب

- تسجيل الدخول بمعرف الطالب وحفظ الجلسة محليًا.
- صفحة شخصية قابلة للتعديل ونتائج الامتحانات.
- تنزيل الكتب وقراءتها داخل التطبيق بواسطة قارئ PDF مدمج.
- حفظ الصفحة والنتائج والفوائد والكتب على الجهاز للاستخدام دون إنترنت.
- تقديم الامتحانات ومراجعة الإجابات عند السماح بها.
- سؤال الشيخ، الدعم الفني، وتسجيل الخروج.
- شهادة خبرة/تفوق تلقائية عند النجاح في امتحان فعّل الشيخ له الشهادة.

### للشيخ

- إدارة الطلاب وطلبات التسجيل.
- إنشاء الامتحان وتعديله بالكامل، بما في ذلك الأسئلة والاختيارات والدرجات والمدة والنشر.
- ربط طالب واحد أو جميع الطلاب بالامتحان ومتابعة النتائج.
- إدارة بنك الأسئلة والكتب والفوائد والاستفسارات والدعم.
- تحديد الامتحان المؤهل للشهادة ونسبة النجاح.
- استخدام لوحة الشيخ من التطبيق دون الحاجة اليومية إلى الموقع.

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `frontend/` | موقع Cloudflare Pages ونسخة PWA |
| `mobile/manara_app/` | تطبيق Flutter للأندرويد |
| `supabase/functions/manara-api/` | Supabase Edge Function وواجهات النظام |
| `supabase/migrations/` | مخطط PostgreSQL وتحديثات الشهادات |
| `migration/` | أدوات الاستيراد والتصدير والنسخ الاحتياطي |
| `release/` | آخر APK مع بصمة SHA-256 |
| `docs/` | معمارية النظام، النشر، التطبيق، والتعافي |

## التشغيل الذاتي

بعد إعداد النسخ المشفر وGitHub، شغّل `START-MANARA-FULL-HANDSOFF.bat` مرة واحدة. بعدها يفحص Windows الموقع والـAPI مرتين يوميًا وعند تسجيل الدخول، ويصلح النسخة المتأخرة، ويرفع المصدر وآخر APK والنسخة المشفرة تلقائيًا. التفاصيل وحدود العمل موثقة في [دليل التشغيل الذاتي](docs/OPERATIONS.md).

## البداية السريعة للمطور

المتطلبات: Node.js 22.13 أو أحدث، pnpm، Supabase CLI، وFlutter عند بناء تطبيق الهاتف.

```powershell
pnpm install
pnpm check:frontend
```

لبناء تطبيق Android:

```powershell
Set-Location mobile/manara_app
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

تفاصيل الإعداد والنشر موجودة في [دليل النشر](docs/DEPLOYMENT.md)، وتفاصيل التطبيق في [دليل الهاتف](docs/MOBILE-APP.md).

## البيانات والأسرار

هذا المستودع العام لا يحتوي بيانات الطلاب، إجاباتهم، كلمات المرور، مفاتيح Supabase السرية، ملفات البيئة، أو النسخ الاحتياطية. ملف `.env.example` يوضح أسماء المتغيرات فقط.

النسخ الاحتياطية التشغيلية تُشفّر قبل مغادرة الجهاز، وتُحفظ في OneDrive. وبموافقة مالك المشروع، تُنشر أحدث لقطة مشفرة فقط في فرع `encrypted-backup`؛ كلمة الاستعادة لا تُخزن في GitHub. راجع [دليل النسخ والتعافي](docs/BACKUP-AND-RECOVERY.md).
